# Visual Reference Images

Start with `REFERENCE-SOURCES.md`, which contains the curated image references, source links and the specific design lessons to extract. Third-party image files are linked rather than copied into this repository.

If the product owner has permission to store a screenshot locally, use these filenames:
- `public-homepage.png`
- `course-catalogue.png`
- `course-details.png`
- `student-dashboard.png`
- `video-learning.png`
- `materials-library.png`

The LMS is video/course-material focused. Prioritise public discovery, student learning and the video player rather than tutor-directory functionality. Do not copy a reference brand or exact layout.

If local images are absent or a remote reference cannot be accessed, the agent must state that and must not claim to have inspected it.
